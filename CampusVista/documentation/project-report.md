## 5. Abstract

CampusVista is a student campus information website. It helps students learn about campus facilities, clubs, events, photographs and contact details. The website is built using only HTML5, CSS3 and Vanilla JavaScript.

## 6. Introduction

Students often need quick access to campus information. CampusVista brings important information together in one simple website. The project is designed as a professional front-end submission instead of separate small tasks.

## 7. Problem Statement

Campus information is often spread across different notices, pages and messages. Students need an easy way to explore facilities, clubs, events and campus photos from one place.

## 8. Objectives

- Create a complete basic HTML web page.
- Build a professional navigation menu.
- Build a simple image slider with JavaScript.
- Make the design responsive for different screen sizes.
- Use accessible labels, focus states and meaningful image text.

## 9. Scope

The scope of this project is limited to front-end development. It includes static content, navigation, responsive layout and an image slider. It does not include a backend, database, login system or real-time updates.

## 12. Project Architecture

The project uses a simple static website architecture.

- `index.html` contains the website structure and content.
- `css/style.css` contains all styling and responsive media queries.
- `js/script.js` contains all interactive behavior.
- `images/` contains the local campus gallery images.
- `documentation/project-report.md` contains this report.
- `README.md` explains the project and task implementation.

## 13. TASK 1: Create a Basic HTML Web Page

Task 1 is implemented in `index.html`.

The page uses a full HTML5 document structure with `<!DOCTYPE html>`, `<html>`, `<head>` and `<body>`. It includes semantic elements such as `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` and `<footer>`.

The website includes a hero section, welcome section, campus information, facilities, clubs, events, gallery and contact section. It also includes paragraphs, multiple images with meaningful alt text, an unordered list, an ordered list and useful hyperlinks.

## 14. TASK 3: Create a Navigation Menu

Task 3 is implemented using `index.html`, `css/style.css` and `js/script.js`.

The navigation menu includes the CampusVista logo and links for Home, About, Campus, Clubs, Events, Gallery and Contact. The Campus item has a dropdown with Facilities, Library, Sports and Student Center.

The desktop menu is horizontal. On smaller screens, it changes into a hamburger menu. JavaScript is used to open and close the mobile menu and dropdown. Accessibility is improved with focus styles, `aria-expanded`, `aria-label` and Escape key support.

## 15. TASK 6: Build a Simple Image Slider

Task 6 is implemented in the Campus Gallery section.

The slider includes five images with captions:

- Central Campus
- Digital Library
- Innovation Center
- Sports Complex
- Student Activities

The slider has previous and next buttons, dots, image counter, smooth transitions and auto-play. Auto-play pauses when the mouse enters the slider and resumes when the mouse leaves. The slider also supports keyboard arrow navigation.

JavaScript functions used:

- `showSlide()`
- `nextSlide()`
- `previousSlide()`
- `startAutoPlay()`
- `stopAutoPlay()`
- `updateDots()`
